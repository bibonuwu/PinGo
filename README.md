# Pingo — Support for every child

Платформа, где родители находят волонтёров и специалистов для занятий с детьми с особыми потребностями
(аутизм, СДВГ, задержка речи и др.). Талисман и гид по приложению — пингвин Pingo.

React 18 + Vite 7, JavaScript (JSX) и обычный CSS. Бэкенд — Firebase: Authentication (email/пароль и Google),
Cloud Firestore (данные и документы специалистов), Hosting (сайт). Всё укладывается в бесплатный тариф Spark. Сайт устанавливается как приложение (PWA),
открывается без интернета с последними данными, адаптирован под телефон и компьютер.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 (если порт занят, Vite предложит следующий)
npm run build        # production-сборка в dist/
npm run preview      # проверить сборку: http://localhost:4173 — здесь работает установка и офлайн
npm run dev:mobile   # открыть с телефона в той же Wi-Fi сети (адрес покажет Vite)
```

## Firebase

Проект `pingo-fc851`, конфигурация веб-приложения — в `src/lib/firebase.js` (ключи не секретные, доступ ограничивают
правила). Нужно включить в консоли Firebase:

- **Authentication → Sign-in method:** Email/Password и Google.
- **Authentication → Settings → Authorized domains:** домен сайта `pingo-kids.web.app` — без этого
  не работает вход через Google.
- **Firestore Database** — создана, правила лежат в `firestore.rules`. Firebase Storage не нужен.

```bash
npm run build
firebase deploy                          # сайт и правила Firestore
firebase deploy --only hosting           # только сайт
firebase deploy --only firestore         # только правила
```

### Бесплатный тариф (Spark)

Проект работает на бесплатном тарифе Spark — привязывать карту не нужно. Firebase Storage для этого не используется
(с 2026 года он доступен только на платном Blaze): дипломы и сертификаты хранятся в Firestore частями по 750 КБ
(`documents/{uid}/parts`), фото перед загрузкой уменьшаются до 2000 px. Лимиты Spark в сутки: 50 000 чтений,
20 000 записей, 20 000 удалений Firestore, 1 ГБ данных; Hosting — 10 ГБ места и 360 МБ трафика в сутки.
При превышении Firebase не выставляет счёт, а до конца суток отклоняет запросы.

Если проект уже переведён на Blaze: Console → ⚙ → Usage and billing → Details & settings → Modify plan → Spark.
Файлы, загруженные раньше в Storage, после этого станут недоступны — специалистам нужно прикрепить их заново.

**Модераторы.** Админ-панель открывается только для почт `toryyy0325@gmail.com` и `aibekabeken47@gmail.com`
(список — `ADMIN_EMAILS` в `src/lib/constants.js` и функция `isAdmin()` в `firestore.rules`, менять оба места).
Достаточно войти с этой почтой (удобнее через Google): аккаунт сам получит роль `admin`, а если это был
специалист — его анкета уберётся из каталога. При регистрации по паролю почту нужно подтвердить по ссылке из письма.
Роль `admin`, выставленная вручную другим аккаунтам, прав не даёт — они увидят экран «Нет доступа».

### Как устроены данные

| Коллекция | Что хранит | Кто видит |
|---|---|---|
| `users/{uid}` | аккаунт: email, избранное, настройки | владелец, модератор |
| `people/{uid}` | публичная карточка: имя, аватар, роль | все вошедшие |
| `children/{id}` | профиль ребёнка; `specialistIds` — к кому он записан | родитель, эти специалисты, модератор |
| `profiles/{uid}` | анкета целиком: черновик, история модерации, документы | владелец, модератор |
| `catalog/{uid}` | опубликованная версия анкеты (без документов) | все вошедшие |
| `availability`, `reviews` | окна расписания, отзывы | все вошедшие |
| `bookings/{id}` | записи на занятия | родитель и специалист записи, модератор |
| `busy/{specialistId}_{start}` | занятые окна без личных данных — защита от двойной записи | все вошедшие |
| `conversations`, `messages` | диалоги и сообщения | два участника диалога |
| `notifications` | уведомления | адресат |
| `complaints` | жалобы | модератор |
| `certificates` | сертификаты, выданные модератором | все вошедшие |
| `broadcasts` | история рассылок модератора | модератор |
| `rooms/{bookingId}/signals` | сигналинг видеозвонка (WebRTC) | участники записи |

Страницы читают данные из локального зеркала (`src/lib/db.js`): после входа `src/services/sync.js` подписывается
на нужные роли коллекции Firestore и держит зеркало актуальным. Сервисы (`src/services`) пишут в Firestore пакетами,
изменения сразу возвращаются в зеркало.

## Установка как приложение

«Профиль → Настройки → Pingo как приложение». В Chrome, Edge, Яндекс Браузере и на Android появляется кнопка
«Установить Pingo», на iPhone — инструкция «Поделиться → На экран „Домой“». Кнопка доступна на `https`
или на `localhost` в production-сборке (`npm run build && npm run preview`).

## Что реализовано

- **Родитель** (Главная / Специалисты / Записи / Сообщения / Профиль): регистрация → мастер профиля ребёнка
  с пингвином-гидом (аватар, имя и дата рождения 1–18 лет, потребности, стиль обучения, доступность, цели);
  каталог с фильтрами (логопедия, репетиторство, психология, эрготерапия, волонтёры), поиском, избранным
  и подбором «Подходит · имя ребёнка»; запись (ребёнок, дата, время, формат, заметка); статусы
  `pending → confirmed / declined / cancelled`; чат; видеоурок; отчёты специалиста и отзывы.
- **Доступность для каждого ребёнка:** размер текста, межстрочный интервал, меньше анимаций, высокий контраст,
  удобное чтение. Pingo предлагает настройки по особенностям ребёнка, они применяются ко всему приложению,
  когда ребёнок выбран в «Кто занимается сегодня?».
- **Специалист / волонтёр** (Главная / Расписание / Запросы / Сообщения / Профиль): анкета с автосохранением
  (заголовок, описание, опыт, 12 специализаций, возраст детей, формат, языки, документы); обучение из 5 модулей;
  модерация `draft → pending → approved / rejected` с причиной; еженедельные окна и разовые даты;
  приём и отклонение запросов; отчёт после занятия; часы волонтёрства.
- **Модератор** (только почты из `ADMIN_EMAILS`): «Обзор» — счётчики, задачи, график регистраций, лучшие по рейтингу;
  анкеты по статусам с просмотром (документы, обучение, история, изменения относительно опубликованной версии),
  одобрение или отказ с обязательной причиной, снятие с публикации; «Рейтинг» — волонтёры и специалисты
  по оценкам (байесовское среднее), занятиям и часам за всё время или 30 дней; «Волонтёры» — подтверждение
  (отметка «Подтверждён» в каталоге) и снятие с причиной; сертификаты (выдать, отозвать; получатель может
  распечатать или сохранить в PDF); удаление отзывов-нарушений; «Пользователи» с поиском и экспортом в Excel;
  рассылки уведомлений родителям, специалистам или волонтёрам; жалобы. Статистику занятий считают агрегатные
  запросы Firestore (индексы — в `firestore.indexes.json`), записи целиком модератору не загружаются.
- **Видеокомната** открывается за 15 минут до начала и только для подтверждённой онлайн-записи.
- Уведомления в приложении и на устройстве, напоминание об открытии комнаты, экспорт и удаление данных.

## Что изменено относительно исходного ТЗ и почему

- **Шрифты.** Bricolage Grotesque, DM Sans и Bebas Neue не содержат кириллицы. Они подключены и используются для
  латиницы и цифр, а русские буквы берутся из Inter (заголовки и текст) и Oswald (подписи в стиле Bebas).
- **Дата рождения вместо возраста** — возраст не устаревает и считается сам; ограничение 1–18 лет сохранено.
- **Модератора нельзя зарегистрировать через сайт** — только выдать доступ в консоли Firebase (см. выше).
- **В каталоге только одобренные анкеты.** Правка одобренной анкеты уходит на модерацию, но специалист
  не пропадает из каталога: родители видят прежнюю версию до решения модератора.
- **Анкету нельзя отправить без обучения и согласий** (из концепции: обучение и верификация волонтёров).
- **Защита от двойной записи:** одно окно — одна активная запись; у ребёнка не может быть двух занятий в одно время;
  записаться можно минимум за час и максимум на 3 недели вперёд.
- **Отменить можно только до начала занятия**; специалист отклоняет запрос, а не отменяет его.
- **Производные статусы для показа:** «Проведено» (подтверждённое занятие закончилось) и «Истёк срок»
  (запрос не подтвердили до начала) — в базе по-прежнему 4 статуса из ТЗ.
- **Вопрос специалисту до записи** — иначе родитель «застревает», если у специалиста нет свободных окон.
- **Согласие законного представителя** при создании профиля ребёнка; жалобы на пользователей.
- **Контраст:** в жёлтом профиле текст тёмный, а не белый — белый на жёлтом плохо читается.

## Структура

```
src/
  lib/          Firebase, локальное зеркало данных (db.js), запись в Firestore, константы, генерация окон, PWA
  services/     вся бизнес-логика: sync, auth, children, profiles, availability, bookings, chat, notifications…
  hooks/        живые запросы к данным (каталог, записи, счётчики), WebRTC-соединение
  components/   UI-кит, Pingo, карточки, чат, шторки, формы
  layout/       оболочка (сайдбар / нижняя навигация), охрана маршрутов, фоновые наблюдатели
  pages/        auth/, parent/, specialist/, admin/, shared/
  styles/       tokens, base, ui, layout, auth, pages, room
public/         иконки PWA, манифест, аватары-пингвины, иллюстрации из макетов
```
